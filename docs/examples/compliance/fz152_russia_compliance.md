# Example: ФЗ-152 (Russia Personal Data Law) Compliance

## User Request

```
Как обеспечить соответствие ФЗ-152 для сервиса обработки персональных данных?
```

## Reasoning

**Domain:** Compliance (ФЗ-152, Russia)
**Complexity:** Medium
**Model:** Sonnet

## Response

### ФЗ-152 Compliance Checklist

#### 1. Категории персональных данных

```markdown
## Категория 1: Общие ПДн
- ФИО, дата рождения, адрес, телефон, email
- Уровень защиты: УЗ-1 (базовый)
- Требования: шифрование, контроль доступа

## Категория 2: Биометрические ПДн
- Отпечатки пальцев, фото лица, голос
- Уровень защиты: УЗ-2 (средний) или УЗ-3 (высокий)
- Требования: усиленная защита, отдельное согласие

## Категория 3: Специальные ПДн
- Расовая принадлежность, здоровье, судимость
- Уровень защиты: УЗ-3 (высокий)
- Требования: явное согласие, шифрование
```

#### 2. Обязательные документы

```markdown
☐ Политика обработки ПДн
☐ Положение о защите ПДн
☐ Согласие на обработку ПДн (форма)
☐ Уведомление в Роскомнадзор (при трансграничной передаче)
☐ Приказ об утверждении документов
☐ Акты классификации ИСПДн
☐ Модель угроз
☐ Техническое задание на СОИБ (система обеспечения информационной безопасности)
```

#### 3. Техническая реализация

```python
# Пример: Согласие на обработку ПДн
from flask import Flask, request, jsonify
from datetime import datetime

@app.route('/api/consent', methods=['POST'])
def collect_consent():
    """
    Сбор согласия на обработку ПДн (ст. 9 ФЗ-152).
    Согласие должно быть конкретным, информированным и сознательным.
    """
    user_data = request.json

    consent_record = {
        'user_id': user_data['user_id'],
        'timestamp': datetime.utcnow().isoformat(),
        'consent_text': """
        Я даю согласие ООО "Компания" (ИНН 1234567890, адрес: ...) на обработку
        моих персональных данных (ФИО, email, телефон) в целях предоставления услуг.

        Срок действия согласия: до отзыва.
        Способы обработки: сбор, запись, систематизация, хранение, уточнение,
        использование, передача.

        Я уведомлен о праве отозвать согласие путем направления письменного заявления.
        """,
        'consent_given': user_data.get('consent', False),
        'ip_address': request.remote_addr,  # Для доказательства
        'user_agent': request.headers.get('User-Agent')
    }

    # Сохранить согласие (для аудита)
    db.consents.insert_one(consent_record)

    return jsonify({
        'status': 'recorded',
        'consent_id': str(consent_record['_id'])
    })


# Отзыв согласия (ст. 9 п. 2)
@app.route('/api/consent/revoke', methods=['POST'])
def revoke_consent():
    """Отзыв согласия — прекращение обработки ПДн."""
    user_id = request.json.get('user_id')

    # Прекратить обработку (удалить или обезличить)
    anonymize_personal_data(user_id)

    # Уведомить пользователя
    send_email(user_id, "Ваши персональные данные удалены")

    return jsonify({'status': 'revoked'})
```

#### 5. Средства защиты (УЗ-1/УЗ-2/УЗ-3)

```markdown
## УЗ-1 (Базовый) — Общие ПДн
☐ Идентификация и аутентификация
☐ Парольная политика (8+ символов)
☐ Антивирус (с обновлением)
☐ Межсетевой экран
☐ Резервное копирование

## УЗ-2 (Средний) — Биометрия, массовая обработка
☐ Все из УЗ-1 +
☐ Криптографическая защита (ГОСТ)
☐ Контроль целостности (СКЗИ)
☐ Обнаружение вторжений (IDS)
☐ Управление обновлениями

## УЗ-3 (Высокий) — Специальные ПДн
☐ Все из УЗ-2 +
☐ Усиленное шифрование
☐ Физическая защита серверов
☐ Видеонаблюдение
☐ Двухфакторная аутентификация
```

#### 6. Уведомление Роскомнадзора

```markdown
## Когда уведомлять:
☑ Трансграничная передача ПДн (в нероссийские страны)
☑ За 30 дней до начала обработки
☑ Форма 1-ПД на сайте Роскомнадзора

## Что указать:
- Цели обработки
- Категории ПДн
- Правовое основание (договор, согласие, закон)
- Меры защиты
- Трансграничная передача (если есть)

## Исключения (не требуется уведомление):
- Обработка на основании ФЗ (налоги, кадры)
- Обработка для личных нужд
- Обработка без передачи третьим лицам
```

## Key Takeaways

1. **Локализация** — первичная запись ПДн граждан РФ на территории РФ
2. **Согласие** — конкретное, информированное, письменное
3. **Уровни защиты** — УЗ-1/УЗ-2/УЗ-3 (зависит от категории ПДн)
4. **Документы** — политика, согласие, уведомление в Роскомнадзор
5. **СКЗИ** — для УЗ-2/УЗ-3 требуются сертифицированные средства (ГОСТ)

**Штрафы:** До 75,000 руб (юрлица), до 6,000 руб (должностные лица)
**Проверки:** Плановые (раз в 3 года) + внеплановые (по жалобам)
**Сертифицированные СКЗИ:** ViPNet, С-Терра, Крипто-Про
