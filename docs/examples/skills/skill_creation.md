## Step 2: Write Skill Workflow

```markdown
# Coverage Check Skill

## Overview
Analyzes test coverage for the current repository and creates a GitHub issue if coverage falls below the specified threshold.

## Input Validation

Required:
- Repository must have a test suite (pytest, jest, go test, etc.)
- Coverage tool must be installed (pytest-cov, nyc, go cover)
- GitHub repository context available

Optional:
- `threshold` (default: 80) — Minimum coverage percentage

## Phase 1: Detect Language & Test Framework

### 1.1 Identify Language

```bash
# Python
if [ -f "pyproject.toml" ] || [ -f "setup.py" ] || [ -f "requirements.txt" ]; then
    LANGUAGE="python"
    TEST_COMMAND="pytest --cov --cov-report=json"
    COVERAGE_FILE="coverage.json"
fi

# JavaScript/TypeScript
if [ -f "package.json" ]; then
    LANGUAGE="javascript"
    TEST_COMMAND="npm test -- --coverage --coverageReporters=json"
    COVERAGE_FILE="coverage/coverage-summary.json"
fi

# Go
if [ -f "go.mod" ]; then
    LANGUAGE="go"
    TEST_COMMAND="go test -coverprofile=coverage.out ./..."
    COVERAGE_FILE="coverage.out"
fi
```

### 1.2 Verify Test Suite Exists

```bash
if [ -z "$TEST_COMMAND" ]; then
    echo "❌ Error: No supported test framework detected"
    exit 1
fi
```

## Phase 2: Run Tests with Coverage

### 2.1 Execute Tests

```bash
echo "Running tests with coverage..."
$TEST_COMMAND

if [ $? -ne 0 ]; then
    echo "⚠️ Warning: Tests failed. Coverage may be incomplete."
fi
```

### 2.2 Parse Coverage Report

**Python (pytest-cov):**
```python
import json

with open('coverage.json') as f:
    coverage_data = json.load(f)

total_coverage = coverage_data['totals']['percent_covered']
```

**JavaScript (nyc):**
```javascript
const coverage = require('./coverage/coverage-summary.json');
const totalCoverage = coverage.total.lines.pct;
```

**Go:**
```bash
total_coverage=$(go tool cover -func=coverage.out | grep total | awk '{print $3}' | sed 's/%//')
```

## Phase 3: Analyze Coverage

### 3.1 Compare to Threshold

```python
threshold = int(args.get('threshold', 80))

if total_coverage < threshold:
    status = "FAIL"
    message = f"Coverage {total_coverage:.1f}% is below threshold {threshold}%"
else:
    status = "PASS"
    message = f"Coverage {total_coverage:.1f}% meets threshold {threshold}%"
```

### 3.2 Identify Low-Coverage Files

```python
# Find files below 80% coverage
low_coverage_files = []

for file_path, file_data in coverage_data['files'].items():
    file_coverage = file_data['summary']['percent_covered']
    if file_coverage < 80:
        low_coverage_files.append({
            'file': file_path,
            'coverage': file_coverage
        })

# Sort by coverage (worst first)
low_coverage_files.sort(key=lambda x: x['coverage'])
```

## Phase 4: Create GitHub Issue (if below threshold)

### 4.1 Check if Issue Should be Created

```python
if status == "PASS":
    print(f"✅ {message}")
    print("No action needed.")
    exit(0)
```

### 4.2 Generate Issue Title

```python
issue_title = f"Test Coverage Below Threshold ({total_coverage:.1f}% < {threshold}%)"
```

### 4.3 Generate Issue Body

```python
issue_body = f"""
## Coverage Report

**Current Coverage:** {total_coverage:.1f}%
**Threshold:** {threshold}%
**Status:** ⚠️ Below Threshold

---

## Low Coverage Files (Top 10)

| File | Coverage |
|------|----------|
"""

for file_info in low_coverage_files[:10]:
    issue_body += f"| `{file_info['file']}` | {file_info['coverage']:.1f}% |\n"

issue_body += f"""

---

## Recommendations

1. **Priority:** Focus on files with <50% coverage
2. **Add tests for:** Uncovered branches, edge cases, error handling
3. **Target:** Increase overall coverage to {threshold}%+

## Next Steps

- [ ] Review low-coverage files
- [ ] Write missing tests
- [ ] Re-run coverage check
- [ ] Close this issue when threshold is met

---

**Auto-generated by Claude Code coverage-check skill**
**Run:** `/coverage-check {threshold}` to re-check
"""
```

### 4.4 Create Issue via MCP

Use the `mcp__github__create_issue` tool:

```python
mcp__github__create_issue(
    owner="your-org",
    repo="your-repo",
    title=issue_title,
    body=issue_body,
    labels=["quality", "testing", "automated"]
)
```

## Phase 5: Output Summary

### 5.1 Print Results

```bash
echo "============================================"
echo "Coverage Check Complete"
echo "============================================"
echo "Language: $LANGUAGE"
echo "Coverage: $total_coverage%"
echo "Threshold: $threshold%"
echo "Status: $status"

if [ "$status" = "FAIL" ]; then
    echo "GitHub Issue: Created"
    echo "Issue URL: $issue_url"
else
    echo "GitHub Issue: Not needed"
fi
echo "============================================"
```

## Success Criteria

- ✅ Coverage successfully analyzed
- ✅ Threshold comparison performed
- ✅ GitHub issue created if below threshold (or skipped if passing)
- ✅ Low-coverage files identified and listed

## Error Handling

| Error | Handling |
|-------|----------|
| No test framework detected | Exit with error message |
| Tests fail | Continue with incomplete coverage, add warning |
| Coverage file not found | Check if coverage tool is installed |
| GitHub API error | Log error, suggest manual issue creation |
```

## CI/CD Integration

**GitHub Actions Workflow:**

```yaml
name: Coverage Check

on:
  push:
    branches: [main]
  pull_request:

jobs:
  coverage:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Install Claude Code
        run: npm install -g @anthropic/claude-code

      - name: Run Coverage Check
        run: claude "/coverage-check 80"
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```
