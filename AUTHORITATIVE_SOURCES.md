## Source Quality Criteria

### Tier Classification

| Tier | Description | Trust Level | Verification Required |
|------|-------------|-------------|----------------------|
| **Tier 1** | Primary authoritative sources (model providers, top universities, standards bodies) | High | Minimal |
| **Tier 2** | Secondary authoritative sources (frameworks, tools, courses) | Medium-High | Cross-reference |
| **Tier 3** | Community sources (forums, newsletters, blogs) | Medium | Full verification |
| **Tier 4** | Unverified sources | Low | Extensive verification |

### Quality Indicators

| Indicator | Description | Weight |
|-----------|-------------|--------|
| **Authority** | Source expertise in the domain | 30% |
| **Currency** | How recent is the information | 25% |
| **Accuracy** | Factual correctness (verified) | 25% |
| **Relevance** | Applicability to our use case | 20% |

### Red Flags (Automatic Downgrade)

- No clear authorship
- No publication date
- No citations or references
- Contradicts Tier 1 sources
- Marketing-heavy content
- Outdated information (>12 months for fast-moving topics)

## Source Management Protocol

### Addition Protocol

```
1. PROPOSE — Identify potential source
2. EVALUATE — Apply quality criteria
3. CLASSIFY — Assign tier
4. DOCUMENT — Add to registry with metadata
5. VERIFY — Cross-reference with existing sources
6. APPROVE — Team review (for Tier 1-2)
```

### Monitoring Protocol

| Frequency | Action | Sources |
|-----------|--------|---------|
| **Weekly** | Check for updates | Tier 1 model providers |
| **Bi-weekly** | Review new releases | Tier 1-2 all |
| **Monthly** | Full registry review | All tiers |
| **Quarterly** | Structural audit | Registry structure |

### Archival Protocol

```
TRIGGER: Source becomes inactive/deprecated
    │
    ▼
EVALUATE: Still relevant for historical reference?
    │
    ├─► YES: Move to ARCHIVED section, add end date
    │
    └─► NO: Remove from registry, log in changelog
```

### Deletion Protocol

```
CRITERIA FOR REMOVAL:
- Source is defunct (website down >3 months)
- Source quality degraded significantly
- Source contradicts multiple Tier 1 sources
- Source is superseded by better alternative

PROCESS:
1. Flag for removal with reason
2. Team review (minimum 2 approvals)
3. Remove from registry
4. Log in changelog with reason
```

## Fact-Checking Protocol

### Verification Levels

| Level | Description | When to Use |
|-------|-------------|-------------|
| **L1** | Trust source | Tier 1 sources, official docs |
| **L2** | Verify with one other source | Tier 2 sources |
| **L3** | Verify with 2+ independent sources | Tier 3 sources, claims that seem unusual |
| **L4** | Deep verification | Critical claims, security-related |

### Fact-Check Process

```
CLAIM RECEIVED
      │
      ▼
┌─────────────────────────────────────────────────────────────────┐
│  STEP 1: Source Classification                                   │
│  ├─► Tier 1: Proceed with L1 verification                       │
│  ├─► Tier 2: Proceed with L2 verification                       │
│  ├─► Tier 3: Proceed with L3 verification                       │
│  └─► Unknown: Proceed with L4 verification                      │
└─────────────────────────────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────────────────────────────┐
│  STEP 2: Cross-Reference                                         │
│  ├─► Check against known facts in configuration                 │
│  ├─► Search Tier 1 sources for confirmation                     │
│  └─► Flag contradictions for resolution                         │
└─────────────────────────────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────────────────────────────┐
│  STEP 3: Resolution                                              │
│  ├─► CONFIRMED: Use claim, cite source                          │
│  ├─► UNCERTAIN: Mark as "needs verification"                    │
│  └─► CONTRADICTED: Do not use, investigate                      │
└─────────────────────────────────────────────────────────────────┘
```
